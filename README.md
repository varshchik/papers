# papers

Notes from the NSAI project — a small research system for working with text,
built around the question: which "necessary" components of language processing
turn out not to be necessary at all.

Each note examines one architectural decision and articulates a principle.
Releases happen as the relevant parts of the system ripen to the point
where it makes sense to describe them publicly. No timeline.
